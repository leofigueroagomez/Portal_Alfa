## Entrega

- `lib/quotes/draftBuilder.ts` implementa el contrato `DraftQuoteInput -> DraftQuoteResult` como DAL `server-only`.
- Resuelve productos desde `products` y actividades desde `labor_activity_catalog`.
- Lee `company_settings.indirect_cost_percent` cuando el input no trae override.
- Usa Banxico SIE SF43718 y el mismo fallback publico USD/MXN del endpoint vigente.
- Crea `quote_groups`, `quotes` en `draft`, `quote_sections`, `quote_items`, `quote_item_labor_activities` y `quote_terms_settings`.
- Antes de insertar compara los ultimos borradores del cliente y reutiliza uno con las mismas notas, indirecto y partidas derivadas.
- Un costo faltante genera `warnings`; no detiene el borrador si existe precio calculado de catalogo.
- Si falla una escritura despues de crear el grupo, intenta eliminar primero la cotizacion parcial y despues su `quote_group`; si RLS u otra condicion impide limpiar, conserva el error original y agrega el detalle de limpieza incompleta.

## Formulas replicadas

1. Precio de catalogo: `products.calculated_sale_price`. Ese campo ya conserva la decision vigente de pricing del producto.
2. Override de margen: `costo convertido a sale_currency / (1 - margen / 100)`.
3. Indirecto: multiplica solo equipo por `1 + indirect_cost_percent / 100`; `indirect_cost_mxn` se extrae para reporte y no se vuelve a sumar.
4. Equipo MXN: `equipment_total_usd * exchange_rate`.
5. Mano de obra: `sale_unit_price_mxn * quantity`.
6. Subtotal/base gravable: equipo MXN + mano de obra.
7. IVA: 16%; total: base + IVA. Todos los campos persistidos se redondean a centavos.

## Fuera de G2 / pendiente de contrato

- No se modifico `app/(admin)/quotes/new/page.tsx` ni el editor de escritorio.
- El input aprobado no incluye sistema/seccion. Por eso productos van a `General` y mano de obra independiente a `Mano de obra`.
- El input tampoco incluye miscelaneos, descuentos, partner, proyecto, diagnostico, areas, viaticos ni condiciones personalizadas. Sus valores quedan en los defaults del alta estandar (MISC y descuentos en cero).
- No se agrego endpoint ni Server Action; G3/G4 deben envolver este DAL con auth/autorizacion en su propia frontera.
- No existe una RPC transaccional. La limpieza compensatoria reduce el litter, pero es `best-effort`: con un cliente sin permiso de borrado por RLS puede quedar un borrador parcial y el error lo reporta expresamente. No se cambio schema, RLS ni auth en G2.
