# Imágenes de producto — Sonos

Coloca aquí las fotos oficiales de cada modelo Sonos.

- **Formato preferente:** `.avif` (fallback automático a `.png`, `.jpg`, `.jpeg`, `.webp`).
- **Nomenclatura:** el `key` del producto tal como aparece en `image_url` dentro de
  `lib/catalogData.ts` (marca Sonos, ids 200+). Ejemplos:
  - `arc-ultra.avif`
  - `era-300.avif`
  - `beam-gen-2.avif`
  - `sub-gen-4.avif`
  - `in-ceiling-6.avif`

Mientras no exista la imagen, la ficha muestra "Fotografía oficial en calibración"
sin romper el layout.
